# Anonymous artifact snapshot

This is the sanitized artifact for the submitted paper *Same Traces, Different
Verdicts*. It is a frozen snapshot built for double-blind review, not a mirror
of a development repository.

What is deliberately absent, by construction: repository history, commit
identifiers, release tags, repository and owner names, remote URLs, CI run
links, and any local filesystem path. The identifiers that bind this artifact to
the reported numbers are **content digests**, which identify bytes rather than
people:

```text
legacy canonical result   SHA-256
9426456393ea4e99f6a15cf3d38b60e2537a2aff98d6143102a2b2bc7f56df5d

dataset manifest          SHA-256
948b94325ae1c8cfbe41bd205fee46b0f500215559ef5cd97a25c27fcf580049
```

The first digest is the legacy evaluated result file shipped below; it is taken
over LF-normalised bytes and the file ships with LF endings, so hashing it
directly reproduces the value on any platform. The second is the manifest over
the external dump described in [DATASET.md](DATASET.md). The Route B result
files record the digests of the inputs they consume in their own `source`
blocks.

`MANIFEST.json` lists every shipped file with its SHA-256 and byte count; it is
regenerated by the build and excludes only itself. Verify it with
`python scripts/verify_artifact_manifest.py`; the command exits non-zero on a
tampered, missing, or unlisted file. `HASH_MAP.json` binds each
canonical input digest quoted by a derived result to the digest of the shipped,
anonymised copy. It records the explicit field whitelist that anonymisation may
change and fails the build if any other field---including suite names, arms,
task identifiers, attack types, metric definitions, or model versions---differs.
`VERIFICATION.md` records the actual test, fault-suite and independent-
recomputation outputs behind the paper's verification claims.

## Install

```bash
pip install -r requirements-test.txt
```

Python 3.11 or 3.12. The analyses are pure Python over local files: no network
calls, no model API calls, no wall-clock time and no RNG state except the
seeded bootstrap.

## Reproduce without the external data

These commands need only files shipped here:

```bash
python experiments/contract/block_set_equality.py
python experiments/statistics/clustered_bootstrap.py
python experiments/statistics/external_clustered_bootstrap.py
python experiments/statistics/power.py
python experiments/identifiability/review_bounds.py
python experiments/attribution/flip_forensics.py
python experiments/faults/run_fault_suite.py
python -m tools.gate_audit.cli validate tools/gate_audit/examples/report_band_block.json
python -m tools.gate_audit.cli claims tools/gate_audit/examples/report_band_block.json \
  tools/gate_audit/examples/claims_bad.json
```

Each writes its result JSON under `.../results/`; a reproduction overwrites the
shipped file, so keep a copy before running it. The fault suite works on deep
copies and hashes its examples before and after; it never mutates them.

## Reproduce Study 2 and the frame sensitivities

Study 2 reads a public run tree. Clone the upstream repository at the commit
printed in the paper, then sparse-checkout the five arms:

```bash
git clone --filter=blob:none --no-checkout <agentdojo-repo> .tmp/agentdojo
cd .tmp/agentdojo
git fetch --depth 1 origin <agentdojo-commit>
git checkout --detach <agentdojo-commit>
git sparse-checkout init --cone
git sparse-checkout set runs/gpt-4o-2024-05-13 \
  runs/gpt-4o-2024-05-13-tool_filter \
  runs/gpt-4o-2024-05-13-spotlighting_with_delimiting \
  runs/gpt-4o-2024-05-13-transformers_pi_detector \
  runs/gpt-4o-2024-05-13-repeat_user_prompt \
  runs/Meta-SecAlign-70B
git rev-parse HEAD
cd -
```

`git rev-parse HEAD` must print the exact commit passed to
`--artifact-commit`; a shallow clone at a branch tip is not the pinned input.
The second-model run is needed for the 12,890-file audit scope, even though the
paired defense comparisons use only the five gpt-4o arms.

Then run the audit into a separate directory:

```bash
python benchmark/external_validity_agentdojo.py \
  --artifact-commit <agentdojo-commit> \
  --out reproduced/external_validity_agentdojo.json
```

The same staged tree feeds the size and reversal analyses:

```bash
python experiments/statistics/sample_size.py
python experiments/sensitivity/reversal_distance.py
python experiments/sensitivity/envelope.py
python experiments/sensitivity/joint.py
python audit/independent_review/recompute.py --mode external
```

Use `--mode offline` to reproduce the shipped counts, rates, reversal geometry,
power and attribution bound without the run tree; offline reports the external
layer as BLOCKED rather than failing. `--mode full` requires the Arrow dump and
a live replay and currently reports BLOCKED.

`envelope.py` and `joint.py` need only shipped JSON and the outcome file;
`sample_size.py`, `reversal_distance.py` and the Study 2 half of `recompute.py`
need the staged run tree.

## Study 1 with the frozen dump

The rule replay that produced the per-trajectory outcomes needs the dump staged
at the path in [DATASET.md](DATASET.md). Check the staging first:

```bash
python scripts/fingerprint_agentdojo_dump.py
```

It must print the manifest digest in [DATASET.md](DATASET.md). The outcomes file
shipped here is the result of that replay; the downstream analyses above do not
need the dump.

## Regenerate the figures

```bash
python scripts/draw_route_b_figures.py
```

Writes the Route B figures from the shipped result files. This needs
`matplotlib`, which is not in either requirements file because the manuscript
build is a separate toolchain.

## Run the tests

```bash
python -m pytest tests/contract tests/statistics tests/sensitivity \
  tests/attribution tests/evaluation_faults tests/audit
python -m pytest backend/tests
```

The first line pins every Route B result, the Claim Auditor examples and the
fault suite. The second covers the engine and the control experiments.

## What is not here

| Absent | Why |
|---|---|
| the ~50.9 MB Arrow dump | 8 MB per-file limit; binaries are not anonymized; upstream terms |
| the public AgentDojo run tree | public upstream; the paper prints the commit; clone it as above |
| the live arm's run manifests and per-cell workspaces | they name a development revision and third-party endpoints; every shipped row carries the digest of the record it came from instead |
| raw live trajectories | they embed usable injection payloads |
| repository history, tags, commit ids | not identifiers of the research; content digests are |
| the E05/E06 external-triage notes | they record public repository URLs and a third-party commit; research process, not promised artifact |
| build residue, caches, dev-only harness state | not part of the artifact |

The Claim Auditor does not decide whether a paper is right. It checks a report
against a schema, classifies a comparison, and rejects a block rate described as
an attack success rate. The numbers and their interpretation limits are in the
paper.
